# My Favorite Singers — Bootstrap 5 Assignment

Open `index.html` in a browser with an internet connection (Bootstrap is loaded through its CDN).

Files:
- `index.html` — Bootstrap grid with `.col-sm-4` for the image and `.col-sm-8` for the table.
- `js/main.js` — a JSON-style object with four singers, looped through when the page loads.
- `css/styles.css` — a few simple custom styles.
- `images/singer.svg` — the image displayed in the first column.

To turn in: upload the **unzipped** project files to a GitHub repository, then submit the ZIP file to your class assignment. Copy the GitHub repository URL into the assignment comments.
